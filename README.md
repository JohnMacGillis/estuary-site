# estuary-site

Deployed build of **Estuary** — free, private help settling an estate in Nova Scotia.

Live: https://johnmacgillis.github.io/estuary-site/

This repository holds **only the compiled output**. It is regenerated from a private source
repository and is not edited by hand — changes made here will be overwritten by the next deploy.

Estuary describes a public court process, tracks paperwork, and drafts correspondence. It is not a
law firm and does not give legal advice.
